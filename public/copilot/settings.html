Connect your own OpenAI account. Usage is billed by OpenAI to the owner of the key.

OpenAI API key

It is checked with OpenAI, stored encrypted on the server and never shown again in full.

How to get a key

  1. Go to platform.openai.com and sign in.
  2. Billing → add credit (USD 10–20 is plenty to start).
  3. Settings → Limits → set a monthly budget so there are no surprises.
  4. API keys → Create new secret key → name it “Sales Copilot” → copy it.
  5. Paste it here and click Save key.
Approximate cost

About USD 0.50–2 per hour of live session; cents for a reply, a screen read or a morning summary.

Without a key

The copilot runs in demo mode: every screen works with example answers so you can try it, but nothing is really transcribed, read or searched.
